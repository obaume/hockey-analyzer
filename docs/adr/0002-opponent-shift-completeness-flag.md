# Per-game flag for opponent shift-tracking completeness, instead of a fixed home/away rule

The map's Notes say the home team gets full individual advanced stats while other tracked teams get lighter team-level reports, "since data on them will be sparser" — which could have been implemented as a hard rule: individual on-ice stats (Corsi/Fenwick-while-on-ice, +/-, zone starts) only ever computed for home-team players. We decided against that: `Game.opponent_shifts_complete` (boolean, default `false`) records, per game, whether the visiting team's `shift_change` events were actually tagged completely enough to trust on-ice attribution, and every on-ice-attribution stat checks this flag rather than a team's home/away status. The map's "sparser" framing describes the typical case, not a hard constraint — a tagger who *does* track a rival team's shifts in full (e.g. a game worth deeper scouting) should get the same individual stats for them that the home team gets, without the data model forbidding it. ADR-0001 already established uniform `Player`/`GameRosterEntry` records for all teams for a similar reason; this extends that principle from identity to stat eligibility.

Rejected alternative: hardcoding eligibility to home-team-only would have been simpler, but would permanently conflate "who is my team" with "how completely did I tag this game" — two independent facts that happen to usually correlate but shouldn't be modeled as one.
