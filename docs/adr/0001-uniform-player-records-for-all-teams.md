# Uniform player records for all teams, not just the home team

The map's Notes say the home team gets full individual advanced stats (RAPM, +/-) while other tracked teams get lighter team-level/tendency reports, which could have meant opponents don't need player-level identity at all — events attributed to a team, not a player. We decided against that: every player, home or opposing, gets a full `Player` record and a `GameRosterEntry`, and events (`shift_change`, `shot_attempt`'s `assist1`/`assist2`) reference players uniformly regardless of team. The "lighter reports" distinction is implemented as which stats get computed over the data, not as a second, player-less recording path — a player-less path would fork the event schema by team and lose cross-game opponent identity (recognizing a repeat rival) for no real savings, especially since opposing rosters will mostly arrive pre-populated via the league API rather than hand-entered.
